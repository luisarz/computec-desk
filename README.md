# COMPUTEC Escritorio

Facturación electrónica (DTE) para El Salvador.

Este repositorio publica **solo los instaladores y las actualizaciones** de COMPUTEC Escritorio. No contiene código fuente.

- **Descarga:** en [Releases](../../releases/latest), el instalador de Windows (`.exe`) o de macOS.
- **Uso:** el programa requiere una **licencia de COMPUTEC** por empresa. Sin licencia vigente no emite documentos.
- **Actualizaciones:** la app avisa sola cuando hay una versión nueva. Un administrador elige cuándo instalarla, y antes se hace un respaldo de la base.
